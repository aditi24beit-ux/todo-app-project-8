# TaskFlow – User & Admin UI designs

Modern purple-and-white To-Do app UI mockups.

## Included
- 9 screens in desktop and mobile layouts (18 editable SVG files)
- Common: Login, Registration
- User: Dashboard, Add/Edit Task, My Tasks
- Admin: Dashboard, Manage Users, All Tasks, Statistics

## Open in Figma
1. Extract this ZIP.
2. In Figma, drag an SVG file onto the canvas.
3. Ungroup the imported SVG if you want to edit individual elements.

These are static UI design mockups, not a working application.

## Suggested GitHub folder
Place the SVG files and this README inside your repository's `design/` folder.
